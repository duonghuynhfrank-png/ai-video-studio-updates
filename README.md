# AI Video Studio updates

Signed Windows application updates for AI Video Studio.

Existing Windows installations without a release service: download [Connect-Updates.zip](https://github.com/duonghuynhfrank-png/ai-video-studio-updates/raw/refs/heads/main/Connect-Updates.zip), extract and run Connect-Updates.cmd once. The connector retains the installed publisher key and user Data. New connected Windows installations receive subsequent updates automatically when online and idle.

[Latest signed release](https://github.com/duonghuynhfrank-png/ai-video-studio-updates/releases/latest)

This repository contains software downloads only. Personal photos, projects, account databases, user knowledge, models and the publisher's private signing key are excluded. Account Data synchronization is a separate service. Windows updates do not install native iPhone or iPad binaries.
